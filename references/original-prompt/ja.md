# XXD Panel 074 オリジナルプロンプト · 日本語訳

> 読解用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数写真を一枚に組まず、写真ごとに個別出力します。全体は3:4の縦位置で、上下二つの領域を厳密に1:1、各50%の高さにします。

上半分には元写真を残し、被写体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の空気を維持します。芸術雑誌、インディペンデント出版物、展示写真の質感になる程度の、ごく軽い上質なカラー調整だけを施します。画面に合わせて周囲の環境を自然に拡張してもよいですが、被写体を引き伸ばしたり、歪めたり、変えたりしてはいけません。

下半分では、写真で最も識別しやすい**主体、輪郭、構造、姿勢、物語上の関係**を抽出します。元画面で本当に残すべき感情、動作、関係、視覚的な暗喩を理解してから、独自コンセプトをもつ**擬似3D角丸アイコン視覚**へ再構成します。写真を単にアイコン内へ縮小せず、最少かつ最重要の要素で元写真の「魂」を再建します。一見して主体が分かり、二度目に関係が読め、三度目に元の感情が伝わるものにします。

アイコンの外形は常に**標準1:1正方形の角丸長方形**を保ち、四辺を等長、角丸を統一、正面平視、比率を安定させ、完全で規格的な高級 App Icon のようにします。引き伸ばし、押しつぶし、傾斜、透視変形、台形化、主体による外形変更は禁止します。角丸正方形は固定された視覚舞台であり、創意、空間、物語はすべてその境界内で生じます。

アイコン内部は**正面平視の擬似3D／2.5D空間言語**です。主体を絶対的な視覚中心とし、周囲には物語を強める少数の環境関係だけを残します。実在感のある前後遮蔽、体積の厚み、高低差、柔らかな切面、局部レリーフ、空間距離で豊かな立体感をつくります。複数要素は異なる深度を持てますが、切り紙を重ねるのでなく、一つの連続空間から自然に育つようにします。等角投影の箱庭、俯瞰模型、紙片の重なり、複雑な写実透視は避けます。

構図では元写真で最も力のある**中心的な視覚関係**を優先します。比率の誇張、局部拡大、前後交差、形の呼応、空間圧縮、象徴的変換で暗喩を強められますが、すべての変化は一つの明確な主題に奉仕させます。明確な視覚中心、鮮明な主体輪郭、良好な負の空間を保ち、縮小しても強い識別性と独自の記憶点を持つようにし、普通の「物体を中央に置く」テンプレートアイコンにはしません。

配色は**上の元写真だけから導き、固定の色メニューを設けません**。主体の同一性と感情を最もよく表す主色、最も生命力のある明色、空間の均衡を担う補助色を見極め、元の色相記憶を保ちながら再調整します。適度に**明度と純度を上げ、濁った混色を除き、寒暖関係を整理し、主従を分け、最も精神性のある色を強めます**。元写真より鮮活で透明感と生命力を高めても、別の配色テンプレートではなく自然に元写真から来たと感じられるようにします。暗さ、古び、平均採色、焦点のない多色、蛍光化、安価なキャンディ色は避けます。

質感は**繊細、マット、柔らかな現代的擬似3D彫刻感**とし、高級編集イラスト、微縮アート模型、ブランド3D視覚の中間に置きます。形には実在する体積と柔らかな階層を持たせますが、過度に滑らか、反射的、CG的にしません。切り紙感、プラスチック玩具、ガラスゼリー、金属光沢、ゲームUIの質感を避けます。

下半分の周囲には大きな清潔な余白を保ち、この一枚の完全な角丸正方形アイコンだけを表示します。文字が必要な場合は、ごく少量の精緻な編集文字をアイコン外に置き、誌面と静かで抑制された関係をつくります。周辺装飾や視覚ノイズは加えません。

全体は**固定角丸正方形の舞台＋元写真の魂の抽出＋正面擬似3D階層＋元写真の色彩再ディレクション＋強い識別性と独自の暗喩**を目指します。ブランド視覚提案やアイコンコンセプト審査に入れられる作品とし、写真サムネイル、切り紙イラスト、等角投影模型、テンプレート化した App Icon にはしません。
